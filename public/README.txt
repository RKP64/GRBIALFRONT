Put your organisation's logo here as logo.svg (or logo.png and change the
reference in src/App.jsx).

Recommended: SVG, transparent background, roughly 4:1 aspect ratio.
It is rendered at 26px height in the masthead.

If no file is present the console falls back to a text wordmark, which is set
by VITE_ORG_NAME in .env (default: KPMG).

Note: logo files are trademarks of their owners. Supply your own asset from
your brand portal rather than copying one from the web.
